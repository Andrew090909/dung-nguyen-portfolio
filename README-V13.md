## Cách upload
1. Backup repo hiện tại.
2. Giải nén ZIP.
3. Upload toàn bộ nội dung bên trong lên root repo, chọn ghi đè file trùng.
4. Commit changes.
5. Chờ GitHub Pages triển khai.
6. Kiểm tra `CHECKLIST-V13.md`.

## Lưu ý
Admin GitHub Pages không thể tự ghi lên repo như WordPress nếu không có backend/OAuth. Bản `/admin/` cho phép chỉnh và tải JSON an toàn, sau đó upload đúng file nhỏ lên GitHub.
