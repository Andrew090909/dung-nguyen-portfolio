BẢN VÁ V9.4 — TẠO / RESET MẬT KHẨU ADMIN

Chỉ cập nhật 2 file trong thư mục admin:
- admin/index.html
- admin/admin.js

Cập nhật lên GitHub:
1. Mở repository.
2. Mở thư mục admin.
3. Add file > Upload files.
4. Chọn 2 file index.html và admin.js trong thư mục admin của bản vá.
5. Commit changes.
6. Chờ Netlify Published.
7. Gửi lại email Invite hoặc Password recovery mới từ Netlify Identity > Users.
8. Mở email mới nhất. Trang /admin/ sẽ hiện trực tiếp 2 ô tạo mật khẩu.
