# V19 — Integrated Digital Global Release Candidate

## Baseline

V19 was created from the V18 source, not from the failed V6–V8 visual experiments. The V5 globe component was integrated into the V18 page system while preserving the existing content architecture and three-language structure.

## Included pages

Seven page types are supplied in Vietnamese, English, and Chinese, for 21 primary pages in total:

1. Home
2. Portfolio
3. Pricing
4. Marketing pricing
5. Video pricing
6. Insights
7. Contact

## Globe system

Every primary page contains one code-rendered rotating globe based on the approved V5 direction. The globe:

- rotates around its vertical axis;
- slows to approximately 8% speed while hovered;
- follows pointer movement with limited tilt and translation;
- pauses when off-screen or when the tab is hidden;
- supports `prefers-reduced-motion`;
- uses animated capability labels;
- keeps a transparent/light presentation without a black rectangular panel.

## Site-wide digital background

The digital background is generated by `assets/js/digital-background-v19.js` and styled by `assets/css/digital-system-v19.css`. It uses light data streams, nearby-node connections, signal pulses, and moving packets. It is intended to read as a contemporary data/AI infrastructure layer rather than a dark space scene.

The effect is applied to all 23 HTML documents in the source: the 21 primary pages, `404.html`, and the post template.

## Routing

Navigation and language switching are statically corrected rather than relying on client-side URL rewriting:

- ordinary navigation remains in the current language;
- VI/EN/ZH switching preserves the current page type;
- desktop and mobile menus use the same routing rules;
- canonical and hreflang tags are included for primary pages.

## Contact form

The V19 form code supports a deployed Google Apps Script Web App and waits for an explicit callback before showing success. The included Apps Script:

- appends a lead to a `Website Leads` tab;
- emails `nguyendhungdung@gmail.com`;
- applies a honeypot check;
- mitigates spreadsheet formula injection;
- returns an iframe `postMessage` confirmation.

The package deliberately leaves `form_endpoint` blank because no deployed `/exec` URL was supplied or verified. Until that value is configured and tested, the form opens an email fallback and must not be represented as connected to Google Sheet.

## Build and validation

```bash
npm run validate
npm run build
```

`npm run validate` writes `QA-REPORT-V19.json`. The deployable static output is generated in `_site/`.
