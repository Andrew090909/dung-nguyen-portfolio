# Dũng Nguyễn Portfolio v12

## Local
Open `index.html` or run `npx serve .`.

## Build
```bash
npm run build
```
Output: `_site`.

## GitHub Pages
Push to `main`, then Settings → Pages → Source: GitHub Actions.

## Netlify
Build command: `npm run build`
Publish directory: `_site`

Portfolio password: `999999`.
