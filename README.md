# Nguyen Studio Portfolio V19

V19 is a controlled integration built from the V18 source. It combines the approved V5 rotating globe, language-safe navigation, page-specific globe labels, a site-wide digital background, and a revised contact-form transport.

## Important status

- The static site builds and passes automated source/browser checks for all 21 VI/EN/ZH main pages.
- The Google Sheet/email form receiver is implemented but **not activated** because `content/site-config.json` does not contain a deployed Google Apps Script `/exec` URL.
- No live GitHub Pages deployment was performed from this package.
- Local headless performance testing identified a desktop frame-pacing risk; real-device and deployed-site verification remain required.
